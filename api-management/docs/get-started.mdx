Not sure where to begin? This page helps you find the right quick start guide based on what you are trying to do.

## What do you want to do?

### I want to manage and govern APIs
You want the full platform experience: a web console to create, deploy, test, and govern APIs visually.

**If you want WSO2 to host it:**

| Guide | What you will do |
| :--- | :--- |
| [Publish your first API proxy](docs:api-management/cloud/introduction/quick-start-guide/) | Create a REST API proxy, deploy it, and invoke it from the cloud console. Takes about 10 minutes. |
| [Publish your first MCP server](docs:api-management/cloud/introduction/quick-start-guide/quick-start-guide-mcp/) | Turn an existing API into an MCP server and call its tools from the cloud console. |

**If you want WSO2 to host the console and you run the gateway (hybrid):**

| Guide | What you will do |
| :--- | :--- |
| [Set up a hybrid gateway](docs:api-management/cloud/api-platform-gateway/self-hosted-gateway/getting-started/) | Connect a self-hosted gateway to the cloud control plane so that API traffic stays in your infrastructure. |
| [Publish your first LLM proxy](docs:api-management/cloud/ai-gateway/llm/quick-start-guide/) | Run an AI Gateway, connect it to AI Workspace in the cloud, and route traffic to an LLM provider (such as OpenAI). |
| [Publish your first MCP proxy](docs:api-management/cloud/ai-gateway/mcp/quick-start-guide/) | Run an AI Gateway, connect it to AI Workspace in the cloud, and route traffic to an MCP server. |

**If you want to run it yourself (API Manager):**

| Guide | What you will do |
| :--- | :--- |
| [Install API Manager](https://apim.docs.wso2.com/en/latest/install-and-setup/install-and-setup-overview/) | Download and set up API Manager on Docker or Kubernetes. |
| [Publish your first API proxy](https://apim.docs.wso2.com/en/latest/get-started/api-manager-quick-start-guide/) | Create and deploy an API through the self-managed Publisher UI. |

### I want to run a standalone gateway (no UI, YAML and CLI only)
You want a lightweight gateway that you can download and run immediately. No control plane or web console is required. You configure everything through YAML files and the CLI.

**For API traffic:**

| Guide | What you will do |
| :--- | :--- |
| [API Gateway: Quick start guide](docs:api-gateway/1.2.0/quick-start-guide/) | Configure your first API proxy using YAML and start routing traffic. |

**For AI traffic (LLMs and MCP):**

| Guide | What you will do |
| :--- | :--- |
| [AI Gateway: Quick start guide](docs:ai-gateway/1.2.0/quick-start-guide/) | Configure an LLM provider and route your first LLM request through the gateway. |
| [MCP proxy](docs:ai-gateway/1.2.0/gateway-artifacts/mcp-proxy/) | Expose an MCP server through the gateway and connect to it from an MCP client. |

### I want to govern AI services at the organizational level
You already have gateways running and now want centralized management of LLM providers, MCP servers, guardrails, and cost controls across your organization.

| Guide | What you will do |
| :--- | :--- |
| [AI Workspace in the cloud: Quick start guide](docs:api-management/cloud/ai-workspace/quickstart/) | Connect an AI Gateway to AI Workspace, configure an LLM provider and an MCP proxy, and call both through the gateway. |
| [Self-hosted AI Workspace: Quick start guide](docs:ai-workspace/1.0.0/getting-started/) | Run AI Workspace locally with Docker Compose, connect an AI Gateway, and send a prompt through an LLM provider. |

### I want to publish APIs and MCP servers in a developer portal
You want a catalog where developers discover, subscribe to, and try your APIs and MCP servers.

| Guide | What you will do |
| :--- | :--- |
| [API Portal and MCP Hub: Quick start guide](docs:api-portal/1.0.0/quickstart-guide/) | Run the self-hosted API Portal and MCP Hub, then publish an API and an MCP server to its catalog. |
| [Use the Developer Portal as a consumer](./guides/ai-and-mcp/discover-apis-and-mcp-servers/api-discovery-and-tryout.mdx) | Discover an API in the cloud Developer Portal, try it, subscribe to a plan, and invoke it. |

### I want to analyze API traffic
You want dashboards and alerts for the traffic that flows through your gateways.

| Guide | What you will do |
| :--- | :--- |
| [Get started with Moesif](./analytics/overview.mdx#get-started-with-moesif) | Find the Moesif setup for your deployment and see your first API calls in the analytics dashboards. |

### I want to monetize my APIs
You want to track API usage, set up paid subscription plans, and implement usage-based billing.

| Guide | What you will do |
| :--- | :--- |
| [Monetize a REST API with Stripe](./guides/ai-and-mcp/monetize-apis-and-mcp-tools/api-monetization.mdx) | Connect Stripe, add a paid subscription plan to an API, subscribe to it from the Developer Portal, and check the billed usage. |
