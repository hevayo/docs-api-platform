## Deploy the Chart

<Tabs groupId="tabs">
<TabItem value="oci-registry-recommended" label="OCI Registry (Recommended)">

```bash
helm install ap-gateway oci://registry.wso2.com/wso2-api-platform/sts/helm-charts/gateway \
  --version 2026.10.0 \
  --namespace ap-gateway \
  --create-namespace \
  --values ./values.yaml \
  --wait \
  --timeout 5m
```

</TabItem>
<TabItem value="local-chart-testing-only" label="Local Chart (Testing Only)">

```bash
  --namespace ap-gateway \

```

## Verify the Deployment

**Check all pods are running:**

```bash
kubectl get pods -n ap-gateway
```

**Check all services:**

```bash
kubectl get svc -n ap-gateway
```

**Controller health check:**

```bash
kubectl exec -n ap-gateway deploy/ap-gateway-controller -- \
  wget -qO- http://localhost:9094/api/admin/v1/health
```

## Upgrade Procedure

**Pull latest chart values to see what changed:**

```bash
helm show values oci://registry.wso2.com/wso2-api-platform/sts/helm-charts/gateway --version <new-version>
```

**Diff current release vs the new chart (requires the `helm-diff` plugin):**

```bash
helm diff upgrade ap-gateway oci://registry.wso2.com/wso2-api-platform/sts/helm-charts/gateway \
  --version <new-version> \
  --namespace ap-gateway \
  --values ./values.yaml
```

**Upgrade:**

```bash
helm upgrade ap-gateway oci://registry.wso2.com/wso2-api-platform/sts/helm-charts/gateway \
  --version <new-version> \
  --namespace ap-gateway \
  --values ./values.yaml \
  --wait \
  --timeout 5m
```

**Rollback if needed:**

```bash
helm rollback ap-gateway --namespace ap-gateway
```

:::note
The controller pod restarts on upgrade. Because the gateway runtime syncs policy configuration via xDS from the controller, keep `replicaCount` at `≥ 2` for the runtime so in-flight requests continue to be served during controller restarts.
:::
