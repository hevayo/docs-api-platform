The API Control Plane is where you design, publish, version, and govern APIs. It enforces policies across all connected gateways from a single web UI or from configuration files.

## What you can manage

- [GraphQL APIs](./graphql-apis/overview.mdx): expose a GraphQL backend through the API Platform Gateway.
